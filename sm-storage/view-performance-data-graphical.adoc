= 在 SANtricity System Manager 中查看圖形效能數據
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以檢視邏輯物件、實體物件、應用程式和工作負載的圖形化效能資料。

.關於這項工作
效能圖表會顯示歷史資料以及目前擷取的即時資料。圖表上標示為即時更新的一條垂直線、可區分歷史資料與即時資料。

*儀表板檢視*

儀表板包含一個顯示儲存陣列層級效能的圖表。您可以從此檢視中選擇有限的計量，也可以按一下 *檢視效能詳細資料* 進入 menu:監控[效能]，然後選擇所有可用的計量。

*詳細檢視*

「效能」頁面上顯示的圖表取決於您的選擇：

* *物件類型* -- 選擇要包含的物件類別（例如，儲存陣列、控制器、資源池和 Volume 群組、應用程式、工作負載、Volume、通道和磁碟機）。
* *物件* -- 為選取的物件類型選取最多五個特定物件。


.步驟
. 選擇 menu:監控[效能]。
. 使用 *物件類型* 和 *物件* 來選擇您要顯示的資料。您最多可以選擇五個物件；使用 *物件* 清單中的搜尋欄位來尋找物件名稱或部分名稱。
+
並非所有物件類型都提供所有計量。儲存陣列和控制器不報告延遲，只有控制器報告 CPU 使用率，只有控制器和通道報告剩餘容量。

. 使用 *時間範圍* 選擇您要顯示的期間。
. 按一下 *Refresh* 。
. *選用：* 在個別圖表上，使用 *比較* 為相同物件疊加另一種計量類型。
. 視需要使用其他選項來檢視效能資料。
+
.其他選項
[%collapsible]
====
[cols="25h,~"]
|===
| 選項 | 說明 


 a| 
時間範圍
 a| 
選取您要檢視的時間長度（5分鐘、1小時、8小時、1天、7天、 或30天）。預設值為1小時。


NOTE: 載入 30 天時間範圍的效能資料可能需要幾分鐘。資料載入期間，請勿離開網頁、重新整理網頁或結案瀏覽器。



 a| 
資料點詳細資料
 a| 
將游標停留在圖表上、即可查看特定資料點的度量。



 a| 
捲軸
 a| 
使用圖表下方的捲軸檢視較早或較晚的時間範圍。



 a| 
縮放列
 a| 
在圖表下方、拖曳縮放列控點以縮小時間範圍。變焦列越寬、圖表的細節就越精細。

若要重設圖表、請選取其中一個時間範圍選項。



 a| 
拖放
 a| 
在圖表上、將游標從某個時間點拖曳到另一個時間點、以放大時間範圍。

若要重設圖表、請選取其中一個時間範圍選項。
