= 在 SANtricity System Manager 中變更工作負載設定
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以變更工作負載的名稱、並檢視其相關的應用程式類型。當目前名稱不再有意義或適用時、請變更工作負載名稱。

.步驟
. 從左側面板，選取 menu:儲存設備[應用程式和工作負載]。
+
顯示 Applications and workloads 視圖。

. 選擇要變更的工作負載，然後按一下功能表：省略符號圖示 [ 編輯設定 ] 。
+
「應用程式與工作負載設定」對話方塊隨即出現。

. *選用：*變更使用者提供的工作負載名稱。
. 按一下「 * 儲存 * 」。
