= 在 SANtricity System Manager 中檢視並儲存表格效能數據
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以以表格格式檢視及儲存效能圖表資料。這可讓您篩選要顯示的資料。

.步驟
. 在「效能」頁面上，按一下 *前往表格檢視*。
+
此時會出現一個表格、列出所選物件的所有效能資料。

. 使用*物件類型*和*時間範圍*選擇要顯示的資料，然後按一下*重新整理*。
. 按一下「*顯示/隱藏欄*」按鈕、選取您要包含在表格中的欄。
+
您可以按一下每個核取方塊來選取或取消選取項目。

. 從表格選單中選擇 *匯出至 CSV*，將表格檢視儲存至逗號分隔值（CSV）檔案。
+
視您的瀏覽器設定而定、檔案可能已儲存、或者系統會提示您選擇檔案的名稱和位置。

+
預設檔案名稱格式為 `performanceStatistics-<storage array name>-yyyy-mm-dd_hh-mm-ss.csv`，其中包括儲存陣列名稱以及檔案匯出時的日期和時間。
