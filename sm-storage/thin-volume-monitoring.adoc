= 了解 SANtricity 軟體中的精簡捲監控
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以監控精簡磁碟區是否有空間、並產生適當的警示、以避免容量不足的情況。

精簡配置環境可以分配比其底層實體儲存設備更多的邏輯空間。您可以選擇 menu:儲存設備[精簡 Volume 監控] 來監控精簡 Volume 在達到分配容量上限之前可以成長多少。

您可以使用精簡型監控檢視來執行下列動作：

* 定義限制精簡磁碟區可自動擴充的已分配容量上限。
* 設定當精簡 Volume 接近最大分配容量限制時，向通知區域（可透過視窗右上角的鈴鐺圖示存取）發送警報（超過警告臨界值）的百分比。


若要增加精簡磁碟區的容量、請增加報告的容量。

[NOTE]
====
System Manager不提供建立精簡磁碟區的選項。如果要建立精簡磁碟區、請使用命令列介面（CLI）。

====
[NOTE]
====
EF80、EF50、EF600/EF600C 或 EF300/EF300C 儲存系統不提供精簡磁碟區。
