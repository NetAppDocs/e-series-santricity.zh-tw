= 在 SANtricity System Manager 中設定效能圖的預設時間範圍
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以變更效能圖表所顯示的預設時間範圍。

.關於這項工作
首頁和效能頁面上顯示的效能圖表、一開始會顯示1小時的時間範圍。偏好設定會儲存在瀏覽器的本機儲存設備中、讓所有使用者都能擁有自己的設定。

.步驟
. 點選視窗右上角的 *User Settings* 圖示。
. 在 Default performance graphs time range to show 下拉清單中，選擇 *5 分鐘*、*1 小時*、*8 小時*、*1 天* 或 *7 天*，並確認要執行此操作。
