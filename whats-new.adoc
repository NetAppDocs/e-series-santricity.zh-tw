[[new-features-in-version-12-10r1]]
== Version 12.10R1 版本新增功能

此版本僅包含少量變更，沒有新功能。如需此版本變更的詳細資訊，請參閱 E-Series SANtricity OS 12.10R1 README。



[[new-features-in-version-12-10]]
== 12.10 版的新功能

[cols="35h,~"]
|===
| 新功能 | 說明 


 a| 
EF50 和 EF80 儲存系統的 SAS 擴充支援
 a| 
EF50 和 EF80 儲存系統現已支援 SAS 擴充，進而提升儲存容量和靈活度。透過 SAS 擴充，您可以將額外的儲存設備機箱連接至 EF50 和 EF80 系統，讓您能視需要擴充儲存環境。對於需要大容量儲存設備解決方案，並希望最大化其在 EF50 和 EF80 平台上投資的組織而言，此功能特別有益。



 a| 
E 系列儲存系統的 NVMe over TCP 支援
 a| 
E 系列儲存系統現已支援 NVMe over TCP，為高效能儲存設備存取提供額外的主機介面選項。NVMe over TCP 能夠實現儲存系統與連接主機之間的高效且低延遲通訊，充分利用 NVMe 協定在標準 TCP/IP 網路上的優點。此項支援增強了 E 系列系統的通用性，使組織能夠在需要或優先使用 NVMe over TCP 的環境中部署這些系統。



 a| 
SANtricity System Manager 的使用者介面增強功能
 a| 
SANtricity System Manager 使用者介面已獲得額外增強，以改善導覽、使用性及整體使用者體驗。這些增強功能包括更新管理工作的版面配置與組織，以及為常見儲存管理作業提供更直覺式的工作流程。



 a| 
擴展對 E 系列平台的支援，以適應新的 SANtricity System Manager 使用者介面
 a| 
針對 EF80 和 EF50 儲存系統在 SANtricity 12.00 版本中推出的全新 SANtricity System Manager 使用者介面，現已擴充以支援更多 E 系列儲存平台。這意味著管理更廣泛 E 系列儲存系統的使用者，現在可以從現代化的介面和強化的使用性功能中獲得優點。擴充的支援包括與特定 E 系列儲存系統機型的相容性，讓使用者能夠在更多的儲存基礎架構中，利用改善的導覽與簡化的管理任務。



 a| 
EF80 和 EF50 系統支援混合效能和容量磁碟機
 a| 
EF80 和 EF50 儲存系統現在支援在同一儲存陣列中使用效能和容量 NVMe SSD 磁碟機，但需符合最低磁碟機數量（效能為 6 個，容量為 12 個）。效能和容量磁碟機必須保留在分隔的資源池和 Volume 群組中。



 a| 
增加標準與精簡 Volume 名稱的字元限制
 a| 
標準與精簡 Volume 名稱的字元限制已從 30 個字元增加至 60 個字元。


NOTE: 如果存在名稱長度超過 30 個字元的標準或精簡 Volume，則不支援降級至 SANtricity 作業系統軟體版本 11.90 或更早版本。如果您打算降級至 SANtricity 作業系統軟體版本 11.90 或更早版本，請在降級前變更所有名稱長度超過 30 個字元的標準或精簡 Volume 的名稱。



 a| 
SANtricity System Manager 使用者介面的最短非活動逾時限制現為 10 分鐘
 a| 
SANtricity System Manager 使用者介面的閒置逾時限制已更新為最短 10 分鐘。先前，最短閒置逾時限制為 15 分鐘。此變更有助於增強安全性，確保使用者介面在閒置 10 分鐘後自動登出。

|===

[[new-features-in-version-12-0]]
== 12.0 版的新功能


NOTE: SANtricity OS 12.0 版本僅相容於新型 EF80 和 EF50 全快閃儲存系統。如果您使用的是 SANtricity OS 11.9 或更早版本，請參閱 link:known-issues.html["已知問題"] 以了解先前版本的新功能清單。

[cols="35h,~"]
|===
| 新功能 | 說明 


 a| 
新型儲存系統型號 – EF80 和 EF50 全快閃儲存系統
 a| 
此版本推出了 EF80 和 EF50 全 NVMe 快閃儲存系統。EF80 和 EF50 每個控制器均支援 24 個 NVME SSD 驅動器和一個控制器間鏡像卡。支援的 NVMe over Fabrics 主機介面包括 NVMe over RoCE、NVMe over IB、EF80 的 NVMe over FC 和 EF50 的 NVMe over FC。兩個系統支援的 SCSI 介面均為 Fibre Channel。EF50 每個控制器最多支援兩個主機介面卡，而 EF80 每個控制器最多支援三個主機介面卡。

EF80 和 EF50 也支援 30TB 或 60TB 大小的高容量 NVMe SSD 硬碟。EF80 和 EF50 只有在陣列中配備 30TB 或 60TB 硬碟時才能使用 Dynamic Disk Pool。



 a| 
SANtricity System Manager 的新使用者介面
 a| 
針對新款 EF80 和 EF50 控制器，SANtricity System Manager 使用者介面經過重新設計，外觀更加現代化。新介面採用左側面板導覽，並增強了易用性，從而簡化了管理任務。


NOTE: 新的使用者介面目前僅適用於採用 SANtricity 12.00 版本的 EF80 和 EF50 儲存系統。如果您使用的是 SANtricity 11.9 或更早版本，請參閱link:https://docs.netapp.com/us-en/e-series-santricity-119/system-manager/index.html["SANtricity 系統管理員 11.9"]以取得使用舊版使用者介面的說明。



 a| 
伺服器憑證的主體別名 (SAN) 現在僅允許使用字母、數字和連字號字元
 a| 
在 SANtricity System Manager 或 Unified Manager 中建立或編輯伺服器憑證時，Subject Alternative Names（SANs）欄位現在僅允許使用字母、數字和連字號字元。此變更增強了安全性，並確保與 SSL/TLS 憑證的業界標準相容。



 a| 
對於 SSD 和基於 NVMe 的系統、動態磁碟集區區段大小現在預設為 32K
 a| 
對於基於 SSD 和 NVMe 的系統上的動態磁碟池，預設區段大小已變更為 32K。先前，這些系統的動態磁碟池預設區段大小固定為 128K。此項變更最佳化了包含大小 I/O 操作混合的工作負載的效能。



 a| 
SANtricity System Manager 現已提供指令碼編輯器
 a| 
SANtricity System Manager 中現已提供全新的腳本編輯器。腳本編輯器可讓您建立或編輯腳本檔案、將腳本檔案儲存至儲存管理站的本機磁碟，或從磁碟載入腳本檔案。腳本編輯器提供語法檢查和命令執行功能，方便您管理儲存系統。如需詳細資訊，請參閱 link:sm-support/use-script-editor.html["在 SANtricity System Manager 中使用指令碼編輯器"^]。

|===
