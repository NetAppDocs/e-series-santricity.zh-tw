= 在 SANtricity System Manager 中開啟磁碟機定位器指示燈
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
在「Hardware（硬體）」頁面中、您可以開啟定位器指示燈、找出儲存陣列中磁碟機的實體位置。

.關於這項工作
您可以找到「硬體」頁面上顯示的單一磁碟機或多個磁碟機。

.步驟
. 從左側面板中，選取 menu:硬體[磁碟機]。
. 若要找到一或多個磁碟機、請執行下列其中一項：
+
** *單一磁碟機* -- 從機櫃圖形中，找到您要在陣列中實際定位的磁碟機。按一下磁碟機以顯示其內容功能表，然後選取 *Turn on locator light*。
+
磁碟機的定位指示燈會亮起。當您實際找到磁碟機後、請返回對話方塊並選取*關閉*。

** *多個磁碟機* -- 在篩選欄位中，選擇實體磁碟機類型和邏輯磁碟機類型。符合條件的磁碟機數量顯示在欄位的最右側。接下來，按一下 *開啟定位燈*。實際找到磁碟機後，返回對話方塊並選擇 *關閉*。
