= 在 SANtricity System Manager 中查看控制器設定
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以檢視控制器的相關資訊、例如主機介面、磁碟機介面和管理連接埠的狀態。

.步驟
. 從左側面板中，選擇功能表：Hardware[Controllers and components]。
. 執行下列其中一項動作以顯示控制器設定：
+
** 按一下控制器以顯示內容功能表、然後選取*檢視設定*。
** 選取控制器圖示（*機櫃*下拉式清單旁）。對於雙工組態、請從對話方塊中選取*控制器A*或*控制器B*、然後按一下*下一步*。
+
控制器設定滑動選單開啟。



. 檢視各區段，以便在控制器屬性設定之間移動。
+
.欄位詳細資料
[%collapsible]
====
[cols="25h,~"]
|===
| 區段 | 說明 


 a| 
詳細資料
 a| 
顯示控制器狀態、日期/時間、型號名稱和更換產品編號。



 a| 
目前組態
 a| 
顯示目前韌體版本和 NVRAM 版本。



 a| 
資料快取
 a| 
顯示資料快取總數。



 a| 
資料快取模組
 a| 
顯示快取模組的位置、狀態和容量。



 a| 
處理器快取
 a| 
顯示處理器快取總量。



 a| 
快取備份設備
 a| 
顯示快取備份裝置的位置、狀態和容量。



 a| 
主機介面
 a| 
顯示每個連接埠的主機介面資訊和連結狀態。



 a| 
磁碟機介面
 a| 
顯示每個連接埠的磁碟機介面資訊和連結狀態。



 a| 
管理連接埠設定
 a| 
顯示管理連接埠詳細資料，包括控制器主機名稱、遠端登入和 IP 網路設定。



 a| 
網域名稱系統（DNS）伺服器設定
 a| 
顯示 DNS 組態、主 DNS 伺服器和備份 DNS 伺服器。



 a| 
網路時間協定（NTP）伺服器設定
 a| 
顯示 NTP 服務和 NTP 伺服器組態詳細資料。

|===
====
. 按一下 * 關閉 * 。
