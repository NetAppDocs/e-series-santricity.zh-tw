= 在 SANtricity System Manager 中新增警報的電子郵件地址
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您最多可新增20個電子郵件警示收件者。

.步驟
. 從左側面板中，選取 menu:警示[電子郵件警示]。
. 選取*新增電子郵件*。
+
「新增電子郵件」對話方塊隨即開啟。

. 在空白欄位中、輸入新的電子郵件地址。如果您要新增多個地址、請選取*新增其他電子郵件*以開啟另一個欄位。
. 按一下「 * 新增 * 」。


.結果
電子郵件提醒頁面會顯示新的電子郵件地址。
