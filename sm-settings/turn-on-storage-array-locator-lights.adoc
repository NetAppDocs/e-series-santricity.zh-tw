= 在 SANtricity System Manager 中開啟儲存陣列定位器燈
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
若要在機櫃中找到儲存陣列的實體位置、您可以開啟其定位器（LED）指示燈。

.步驟
. 從左側面板中，選取 *系統*。
. 在 *一般* 下，按一下 *開啟儲存陣列定位燈*。
+
「開啟定位燈」對話方塊開啟，對應的儲存陣列的定位燈亮起。

. 當您實際找到儲存陣列後，請返回對話方塊並選取 *關閉*。


.結果
定位燈會關閉、對話方塊會關閉。
