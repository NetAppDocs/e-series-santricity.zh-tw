= 在 SANtricity System Manager 中為 SNMPv2c 陷阱新增社區
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您最多可以新增256個SNMP v2c設陷的社群名稱。

.步驟
. 從左側面板中，選取 menu:警報[SNMP 警報]。
+
陷阱目的地和社群名稱會出現在表格中。

. 選擇*設定社群*。
+
「設定社群」對話方塊隨即開啟。

. 選取*新增其他社群*。
. 輸入新的社群名稱、然後按一下「*儲存*」。


.結果
新的社群名稱會顯示在 SNMP 警示頁面上。
